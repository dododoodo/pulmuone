### 1. 이미지 슬라이드 및 모달 팝업 창

### 2. 반응형 웹 제작
   - 모바일(~480px), 태블릿(~1024px), PC(1024&#126;1700px) 해상도 지원
     
### 3. 버튼 또는 이미지 클릭시 외부사이트로 연결
   - 버튼이나 이미지에 링크를 걸어 클릭시 그 해당 사이트로 이동하게 지원

## 🔧 초기 개발 환경 세팅
### 1. 프로젝트 생성
- 개발 팀장의 프로젝트를 받아 팀원 각자 맡은 파트의 작업 폴더 생성

### 2. 폴더 구조 설계
- src 폴더 내에 폰트,음악,비디오를 첨부
- scss 폴더, js 폴더 등으로 스타일 또는 스크립트 분리

### 3. 전역 스타일 적용
- 기본 레이아웃 설정 등 작업 전 필요한 전역 스타일 적용

### 4. 코드 통합 및 배포
- Github Desktop을 이용하여 branch에 프로젝트 커밋
- 각 브랜치의 데이터를 메인에서 통합시켜 완성


## 💥 트러블 슈팅(메인/뉴스룸)
- 화면 사이즈가 변경되면 스크롤 막기 기능이 적용되지 않는 문제 발생
  ⇒ **해결 방법**: addEventListener로 미디어 쿼리의 값이 변경될 때마다 checkMobile 함수를 실행시켜
  화면크기가 변경될 때마다 실시간으로 감지할 수 있도록 명령해 제대로 동작할 수 있도록 해결


- 랜덤 이미지 및 링크가 중복으로 반복 출력되는 문제 발생
  ⇒ **해결 방법**: 배열에서 랜덤 인덱스를 선택해 요소를 제거(pop/splice)함으로써,
  이미 출력된 이미지가 다시 선택되지 않도록 중복을 방지



## 💭 프로젝트를 통해 배운점
이번 프로젝트를 통해 원활한 소통의 중요성을 체감했다.
초반에는 각자 맡은 업무에 집중하느라 커뮤니케이션이 부족했고, 그로 인해 수정할 부분이 많아졌다.
하지만 이후에는 작업물을 주기적으로 공유하고 피드백을 나누며 완성도를 높일 수 있었고,
자연스럽게 팀워크도 향상되었다.
효율적인 협업과 꾸준한 의견 교환이 프로젝트 완성에 큰 영향을 준다는 것을 배웠다.
